# Kamo Rogue

階ごとに敵を倒しながら進む、2Dローグライトアクションゲームです。

- ブラウザ版: [Kamo Rogue](https://youkin06.github.io/KamoRogue/)

## 概要

- 各階の敵をすべて倒すと次の階へ進行
- 階クリア時にアビリティを獲得して強化
- 地下5階を突破するとゲームクリア

## 操作方法

- `A` / `D`: 左右移動
- `W`: ジャンプ
- `J`: ショット
- `K`: ガード（アビリティ「シールド」取得時のみ）
- 移動キーをダブル入力: ダッシュ（アビリティ「ダッシュ」取得時のみ）
- `W` をダブル入力: ダブルジャンプ（アビリティ「ダブルジャンプ」取得時のみ）
- `Enter`: 開始 / 再スタート / タイトルへ戻る

## ローカル実行

```bash
pip install -r requirements.txt
python App.py
```
